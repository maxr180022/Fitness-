# Фитнес

Личное приложение для тренировок и питания (PWA): ставится на телефон как обычное приложение.

- Подходы, повторы, время тренировки и замеры хранятся только на телефоне.
- Контент лежит в `data/program.json` (тренировки и упражнения) и `data/nutrition.json` (питание). Видео лежат в `media/`.
- Чтобы обновить контент, достаточно изменить эти файлы и запушить в `main`. Приложение само подтянет новую версию при открытии, пересборка и переустановка не нужны.
- Если заменяешь видео, давай новому файлу новое имя и меняй путь в `program.json`, чтобы телефон не показывал старый кэш.

Установка на Android: открыть ссылку в Chrome → меню ⋮ → «Установить приложение».
